CI/CD Pipeline Gate Generator

Integrate SEALED into your continuous integration workflow to block pull requests with safety or regulatory regressions.

.github/workflows/ai-compliance.yml 
# SEALED CI Gate
name: AI Compliance & Safety Gate
on: [push, pull_request]

jobs:
  sealed-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install SEALED CLI
        run: |
          curl -sSL https://get.sealed.security/linux-x86_64 | tar -xz -C /usr/local/bin

      - name: Execute Offline AI Compliance Audit
        run: |
          # Block outbound network egress to guarantee zero telemetry
          sealed scan . --output-dir ./audit-artifacts --offline

      - name: Archive Compliance Evidence Pack
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: sealed-evidence
          path: |
            ./audit-artifacts/report.html
            ./audit-artifacts/evidence.zip

Zero-Telemetry & Air-Gap Guarantee

SEALED never contacts any server belonging to its authors.

  • Zero Telemetry: No analytics, crash reporting, license verification, or update checks exist in the binary.
  • Strict Egress Control: The network is disabled by default. Connections are only permitted if you explicitly configure an AI endpoint you control.
  • Offline Testing: This guarantee is verified in CI by severing the network and asserting the full scan completes.
